# Janusz-s-Revange — the PrizeBlox prank page

**This is a harmless prank.** PrizeBlox is a joke page that pretends to hand out free "Blox Bucks" (an invented currency). After a few silly steps it shouts **"GOTCHA! You just got PRANKED"** and sends you to Rick Astley's *Never Gonna Give You Up* on YouTube.

- **Collects no data.** There are no forms or text inputs, and nothing is stored or sent. No cookies, no analytics, no tracking, no third-party scripts.
- **The only outbound link** is the YouTube video `https://www.youtube.com/watch?v=dQw4w9WgXcQ`. The only other external request is the Google Fonts stylesheet.
- **Not affiliated** with any real game or company. All platform names (BloxWorld, FortCraft, SteemBox) are made up.

Live: https://cor3man.github.io/Janusz-s-Revange/
